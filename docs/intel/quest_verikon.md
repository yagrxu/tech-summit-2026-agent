## ✅ 实现必须命中的 16 条（Gate A/B 的评分面）

1. **周期展开是第一步**：`Cycle 1–6, Day 1/8/15` 看着 3 列，实际 **6×3=18 次访视**。本项目单中心 54 次访视就是这么来的。
2. **格子是次数，不是勾**：PK 一次访视可采 **8 个时间点**、生命体征一次测 3 次，每点单独收费。按勾算单中心少算数千元，全研究数十万。
3. **格子可能是条件**：「仅育龄期女性」「疑似进展时」「按需」「研究者判断」——**条件写在表格脚注里，不在格子里**。
   必须为其设**预期发生率**，且**必须有人填写 + 记录假设依据**（合规审计会查）。
4. **六层叠加，顺序不能乱**：① 受试者层直接费用（次数×发生率×单价）② 研究者劳务 ③ 方案层固定费（启动/伦理/档案/结题）
   ④ pass-through（实报实销）⑤ 受试者补贴 ⑥ 管理费 Overhead。
5. **管理费基数是谈判焦点，不是比例**：1+2 层通常计入；**第 3 层有争议**；第 4、5 层通常不计入。
   同样写 25%，基数口径不同**总额能差 10% 以上**。→ **预算表必须显式打印一行「管理费基数 = 第 X 层至第 Y 层」**。
6. **付款方字段**：每个费用项标 `申办方直付 / 中心结算 / 受试者`，**汇总只取"中心结算"**。
   **Central Lab 费用由申办方直接与中心实验室结算，不进中心预算；Local Lab 进。**申办方提供的设备耗材不得重复计费。
   → 原文：「一个字段可以消除一整类人工错误」。**这正是那 96 万重复计费的解药，要在方案里点名。**
7. **授权总额 ≠ 实付金额，两个数必须同时给**：授权按**计划**入组算（合同上限，财务/采购看）；
   实付按**实际完成访视**结算（临床运营/中心财务看）。现金流预测基于实付模型。
8. **每个金额字段带「是否含税」+ 适用税率**：申办方按不含税编制、医院按含税报价，天然错位；管理费税率可能不同。
   口径不对齐的后果不是算错，是**签署后财务无法入账、要重签**。
9. **Amendment 级联**：Amendment → SOA 变更 → 每中心重算 → 判是否触及「重大变更」阈值
   → 是则 CTA 补充协议走完整机构办审批，否则换预算附件 + 双方书面确认。
   III 期平均 2~3 次 Amendment × 40~50 家 = **80~150 次重算**。
10. **重算基准是该中心「上一版已签署」的版本，不是最初草稿** → **版本管理不能只留最新版**。
11. **可追溯性（= 林静的点头条件）**：每笔金额要能回答——来自**哪个 SOA 格子、哪张费率表、该表的哪个版本**。
    **费率表版本不可原地修改**，否则历史预算无法复现。这是审计要求，不是偏好。
12. **输出形态**：多 Sheet Excel（访视费用明细 / 费用标准对应关系 / 汇总与付费日程）+ 一份 CSV 供财务导入。
    **合同正文引用的金额必须与预算表汇总页一致** —— 不一致是签署后返工常见原因。
13. **Word 技术形态**（CTA DOCX 要处理的真实对象）：修订追踪 `<w:ins>` `<w:del>` **`<w:rPrChange>`**、
    批注 `<w:comment>`（判断意图的关键）、内容控件 `<w:sdt>`、纯文本占位符 `【】`/连续下划线。
    **`<w:rPrChange>` 格式变更不能忽略** —— 只改数字格式或编号层级，可能实质改变条款适用范围。
    **同一模板里三种占位符混用是常态**，不能假设只有一种。
14. **其他条目**：伦理委员会费 = 第 3 层；**尾款保留 Holdback 5%~10%**（结题后付）；
    **筛选失败** = 筛失人数 × 筛选访视费（筛失率需人工设定）；**非计划访视**单独定价、按估计次数预留。
15. **同一程序三个名字**：方案层英文名 → 公司标准名 → 医院收费项名。第 5 步映射不准，第 6 步单价就匹配错。
16. **审批权限边界**：Legal 只审 CTA 主协议法律条款、**对法律条款有否决权**；Finance/Procurement 管超阈值；
    **Compliance 对超 FMV 有否决权，且要求偏离留痕**。

## ⚠️ 时间线上的坑（别承诺压缩机构审批）

四条并行轨道：伦理 4~8 周 / **合同谈判 6~16 周（通常是关键路径）** / HGR 人类遗传资源审批 3~6 个月（涉样本出境时一定是）/ 试验用药进口 8~12 周。

> 原文：**「合同周期存在制度性下限。即使预算表瞬间生成，机构办的内部评审排队依然在。」**
> 评估改进空间时**必须把 6~16 周拆成「编制与谈判往返」和「机构内部审批」两段 —— 后者不由申办方决定。**

**→ 这是本关最大的话术陷阱**：绝不能说"我们能把合同周期从 16 周压到 X 周"。
只能说"我们压缩的是编制与谈判往返这一段，机构内部审批段不由申办方决定，我不替你们承诺"。
