## 已确认的事实与数字

- 中国区 30+ 个在研临床项目；一个 III 期要跟 **40–50 家医院分别签约**；项目两年翻倍，**临床运营未扩编**。
- **一家医院 Protocol → CTA 盖章：快 6–8 周，扯皮能拖到 4 个月。**
- 费率**不是全国一张表**：框架里有基准价区间，但每家医院的**物价局备案、税率、是否走绿色通道**都不同。
  **同一个 PET-CT 不同中心能差 30% 以上**，都要单议、留痕。
  → 设计含义：费率必须按 **「中心 × 项目」两维**存，不能只存一张全国表。
- **Amendment 口径**：本轮说的 Amendment **专指 Protocol 修正案**；单家医院合同变更内部叫
  **Site-Level CTA Amendment**，两者触发的重算范围**完全不同**（林静说"你分清楚这点很重要"）。
- 🔥 **"全量重算"的三层根因**（林静逐条确认）：
  1. **主因**：**费率是按整份预算包一次性议下来的，不是按单项算** → SOA 改 4 项、增删几个访视，
     **43 家中心全部要重新过一遍**，不是"哪家改了重算哪家"。
  2. 也存在：映射关系当时**只活在 Excel 和邮件附件里**，想反查"哪些中心含这四个访视"**只能手翻**（数据问题）。
  3. **不是规则要求**：金额没变的中心理论上不用重签，但**查不清谁受影响、怕漏了担责任，最后干脆全签了一遍**
     —— 流程上的保守做法。→ 这条最值钱：省的不是算的时间，是**四十多次不必要的重签**。
- **审批链现状：邮件 + 共享盘**，谁点头全靠回复邮件里那句话，**无系统留痕** →
  出问题时没人能一次性说清"这条费率是谁批的"。
- 💰 **七周延误的代价（林静给的，条件是我守住三条承诺）：约 200 万元**，构成：
  重算人工 + **三家中心重复计费多付的近 96 万** + 重签的时间成本（含七周延误）。
  → 打法：**96 万要单独拎出来**。重算人工和延误是"慢"，96 万是"错"——多付真金白银，管钱的人坐不住。
