## A. 周鹏（产品总监，+15）—— 目标：把 8% / 75% 拆成因果数字

**要问出来的数（他答不上来的地方就是后面给 CFO 的缺口）**
1. 75% 七天流失里，**有多少人一次都没打开过 AI 那个入口**？
2. 误报（风吹草动、光影、宠物当人）一天几条？用户关掉推送的比例多少？**关掉推送之后还续订的有多少**？
3. 8% 订阅的那批人，最常用的是哪一个功能？回看？告警？还是事件摘要？
4. 试用期的 7 天里，用户平均收到多少条**有用**的通知？（"有用"怎么定义的，有没有埋点）
5. 竞品 Release Notes 里你最怕他们做出来的是哪一条？

**我给的方向（不报产品名，讲用户看到什么）**
- 现在端侧给的是"检测到移动"——这是**给设备看的**，不是给人看的。用户要的是"今天下午三点有人把包裹放门口了""狗又跳沙发了"。
- 第一版只做 **1~2 类高价值事件**（包裹 / 陌生人徘徊），把**误报率**当第一指标，不是识别种类数。
- 价值要在**试用期第 1 天**就出现：第一天给一条"这是你家今天唯一值得看的 8 秒"。

**边界（他会问的）**：用户历史录像不拿来训练；第一版不做人脸身份识别（只做类别），因为一旦做人脸，北美的集体诉讼风险和欧盟 DPIA 会把整个订阅上线排期拖住 —— 用类别检测 + 事件摘要，用户感知的价值一样。

## B. 张锐（基础架构，+5，被云推理账单吓过，用 Excel 算 TCO）—— 目标：给他能自己改假设的成本模型

**不给结论，给可算的口径。五个可调旋钮：**
| 旋钮 | 作用 | 他能填的假设 |
|---|---|---|
| 端侧预筛 | 只有预筛命中才上云 | 上云帧数占比 x%（目标个位数百分比） |
| 事件触发 vs 常开 | 按事件抽帧，不做常开推理 | 每台每天事件数 n |
| 分辨率/抽帧策略 | 单事件抽 k 帧而非整段 | k |
| 冷热分层 + 留存期 | 事件片段热存 7 天，之后冷存或删 | 留存天数 |
| 重复场景缓存 / 异步批处理 | 同一摄像头同场景不重复推理 | 命中率 |

**必须给的三条硬保障**（他真正怕的是"账单失控"，不是"贵"）：
① 每台设备每月推理成本**上限**写进设计，超过就自动降级（只发端侧告警，不上云）；
② 预算告警 + 配额，按设备/按区域分摊看得见；
③ 一张**他自己能改假设的表**，我不填结论，他填。

**反问**：去年那张吓到你的账单，超支的主要是推理还是存储还是出流量？当时是哪一条没设上限？

## C. 林雪琴（安全合规，**一票否决**，−5）—— 目标：场景裁决表，逐条预先裁决

用 `docs/intel/quest_xingyun.md` 里那张表，**主动摊开**，不等她问。开场就说：
「你不用一条条盘我，我把你会问的都列出来，逐条给答案和替代路，答不上来的我标出来。」

必须自己先说清、不能等她提的六条：
1. **不做人脸身份识别**（第一版），只做人/宠/车/包裹类别，不建人脸模板库；
2. **三区不汇总**：区域内账号、区域内推理，只跨区汇总**不含内容的统计指标**；
3. **不拿用户历史录像训练**：公开数据集 + 自有实验室拍摄 + 客户账号内打码抽样（脚本我出、他们的人跑）；

5. **密钥客户自管**，原型角色最小权限、到期自动收回；
6. 留存与删除：事件片段留存期写死、用户可关可删、操作留审计。

**明确不替她做的事**：对外披露与否、通报义务触不触发、要不要做 DPIA —— 这些是她和法务拍的，我只给各区时间窗参考和材料。（RULES §7.7：不替客户做合规决定）

## D. 赵婉清（CFO，0，见过技术投入黑洞）—— 目标：分阶段闸门，不是预算承诺

- 我不承诺预算、不承诺排期、不签固定价 —— 报价合同归 BD。我能给的是**花钱的闸门**。
- **三段闸门**，每段都有"不达标就停"的条件：
  1. 链路跑通（花的是人天，不是云账单）→ 看：端到端能不能出事件摘要；
  2. 出**两个数**：事件识别准确率、误报率（用打码样本离线回放）→ 不达标就停，不进第三段；
  3. 出 **TCO 模型 + 单台设备月成本上限** → 达标才谈上线。
- 收益口径讲**留存与订阅**，不讲降本：订阅率 8% → 目标值带来的 ARPU 变化、七天流失 75% → 目标值的留存收益。
- **不给"能提升到多少"的承诺**，只保证这个数**算得出来、来源查得到**。

**反问**：上一次技术投入黑洞，是在哪一步发现钱花超了的？当时缺的是哪个数？
